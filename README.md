Forecasts the Yes price of every trading market of Polymarket's "Next CEO of NVIDIA?" event at every minute of the 4 hours after each checkpoint, as five quantiles (5/25/50/75/95%). Persistence median plus a per-market volatility spread estimated from each market's last 24 hours of 1-minute prices, with deliberately wide tails for the market's jump risk.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
